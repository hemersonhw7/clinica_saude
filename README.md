# 🏥 VidaPlena Clínica de Saúde

Landing page estática desenvolvida como projeto acadêmico para uma clínica de saúde fictícia.

## 📋 Sobre o projeto

O projeto tem como objetivo apresentar uma solução web simples, moderna e responsiva para uma clínica de saúde, facilitando o acesso dos pacientes às informações sobre os serviços oferecidos e os profissionais da clínica.

## 🩺 Serviços apresentados

* Atendimento médico
* Exames laboratoriais e de imagem
* Atendimento de enfermagem
* Outros cuidados de saúde

## 👥 Equipe

A landing page apresenta uma equipe fictícia composta por três profissionais, com suas respectivas imagens e funções.

## 📬 Formulário de contato

A página possui um formulário estático contendo:

* Nome
* E-mail
* Cidade
* Estado

O formulário é apenas demonstrativo e não realiza o processamento ou armazenamento dos dados enviados.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* Visual Studio Code

## 📱 Características

* Design moderno
* Layout responsivo
* Navegação entre as seções
* Imagens ilustrativas
* Apresentação dos serviços
* Apresentação da equipe
* Formulário de contato
